# ChatGPT 账号提供商

在“设置 → 提供商 → ＋”选择“ChatGPT · 账号登录”，添加后进入配置页，点击“登录 ChatGPT”。
系统浏览器完成授权后返回 RikkaHub，到“模型”页获取并选择模型，再在聊天中选择该模型。
配置页可查询订阅使用窗口、重置时间、重新登录或退出登录。

此实现从本机参考仓库 `D:\PythonProject\ky\main\rikkahub` 的 `5ad19405` 版本移植，
使用其 Codex OAuth 参数和 ChatGPT/Codex 后端。它使用账号获准的 Codex 订阅额度，
可用模型、套餐限制、区域与工作区权限由服务端决定。它不把订阅余额转换成 OpenAI API Key 额度。
官方对两种认证和计费路径的说明见 <https://learn.chatgpt.com/docs/auth>。

## 实现范围

- 独立的 `ProviderSetting.ChatGPT` 类型，不接受 API Key 或自定义请求地址。
- OAuth 使用 PKCE S256、随机 state 和系统浏览器；回调仅监听 `127.0.0.1:1455/auth/callback`。
  临时前台服务在授权期间保活，取消、完成或五分钟超时后关闭监听。
- 每个提供商串行刷新令牌；过期前五分钟刷新，HTTP 401 至多额外刷新重试一次。
  刷新使用独立网络调度器，调用方取消不会中断已发出的刷新；退出、删除和重新登录不会被旧刷新覆盖。
- 对话走固定 `/backend-api/codex/responses`，复用当前消息结构，支持流式与聚合响应、工具和加密推理历史。
  不支持的采样参数不会发送，保存与流式参数使用端点要求的值。
- 模型列表和用量来自账号服务端；缺失用量不会显示成“无限”或“剩余 100%”。
- 分享、二维码导入以及 Web 设置事件不携带账号凭据；模型覆盖不复制账号配置。
  授权、刷新和账号推理不进入应用请求日志，也不跟随 HTTP 重定向。

## 凭据与兼容性

凭据随 Android 私有设置持久化，与现有提供商配置一样进入完整备份、WebDAV 和 S3 同步。
这类备份含登录会话，应作为个人配置保存。跨设备恢复同一刷新令牌可能导致旧设备需要重新登录。
“退出登录”清除本应用保存的会话，不会退出系统浏览器中的 ChatGPT，也不撤销其他设备会话。

授权时须由本机浏览器打开回调地址。若 1455 端口被其他应用占用，先结束另一场授权，再重试。
此版本依赖参考仓库使用的 Codex 后端约定；如果服务端调整客户端准入、模型目录或接口，可能需要更新。

本机离线 JVM 测试涵盖请求体、工具 call_id、没有 Content-Type 的流、失败和截断流、PKCE、
回调 state/重复回调、并发刷新、退出时刷新、删除提供商、凭据分享与 Web 脱敏。
运行 `scripts/Invoke-IntegrationChecks.ps1` 执行相关模块回归。
手机上的真实浏览器授权、前台服务行为和实际额度扣减，需要使用自己的账号在设备上验收。
