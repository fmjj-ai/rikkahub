## 使用

1. 在助手的本地工具设置中开启「交互式可视化」。存量和新建助手均默认关闭，开启后为主聊天请求追加完整协议说明。
2. 界面设置中的「显示交互式可视化」默认开启。关闭后显示原始代码；历史助手图块的显示不要求当前助手继续开启生成能力。
3. 例如向助手发送：「用交互图形演示单总线 CPU 执行 R1 = R1 + R2，支持上一步、下一步。」
4. 图块中的按钮和滑块在本地更新；卡片提供重置、查看源码与复制。

## 已完成

- `rikka-viz` v1：严格 JSON、重复键检测、表达式白名单、惰性条件、原子动作、滑块量化与资源预算。
- 原生 text、row、column、button、slider、scene，以及 rect、line、circle、text、polyline、path、repeat、plot 图元。
- Markdown AST 识别真实顶层围栏；占位节点在同一份文档中渲染，保留引用链接、表格、公式和 HTML 路径。原始 JSON 不经过显示正则替换。
- 未闭合围栏只显示生成状态；取消后显示未完成提示。每条消息最多自动渲染 4 块，超额保留源码。
- 会话 ViewModel 保存最多 48 个解析结果和交互状态。键包含对话、消息、part、围栏序号和内容 SHA-256；滚动离屏、继续输出和主题变化不重置。删除或切换消息版本时清理不再使用的条目。
- 提示词仅在主聊天请求最终装配阶段按开关注入；不改用户系统提示词、历史内容、压缩、标题或翻译请求。
- 通知与朗读使用图名及周围正文；保存、上下文、分享和导出保留原始源码。
- 保留已有函数绘图工具、普通代码块、HTML/SVG/Mermaid 预览路径，无新增依赖。

核心协议实现位于 `app/src/main/java/me/rerere/rikkahub/data/visualization/`；界面实现在 `app/src/main/java/me/rerere/rikkahub/ui/components/visualization/`。
